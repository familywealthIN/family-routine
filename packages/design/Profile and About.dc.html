ProfileProfile page: you first, then the settings you can change, then what's fixed, then connections and the danger zone

From ProfileTime.vue: the yellow "most settings are read only" banner is gone; read-only rows carry a lock instead. Time format uses the sliding switch and previews 09:00 vs 9:00 AM. Time zone is a real select. The Rate values become the D/K/G cards. Goal auto-check thresholds become the roll-up chain (5 days → week, 3 weeks → month, 9 months → year). Connect AI keeps the MCP Server URL, Client ID and a masked secret, with copy buttons; the four platform guides become chips with numbered steps. The legacy API key generates in place. Delete account asks you to type DELETE in a modal.
