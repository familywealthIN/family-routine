AgentsAgents page: every worker glued to a routine, its live lifecycle, and its last result, one tap from editing

Built from the Agent schema: name, the bound routine (taskRef), start and end events (URL or cURL, with the goal_id placeholder substituted), executionStatus, success and failure counts, and last run with its result or error. List cards show the lifecycle as a status ring, which breathes while listening, the same signal as the tick button on Home. The detail view shows the four-step lifecycle, both events, and the last result rendered the way the goal item shows its reward (or the error). Run test walks the lifecycle. New and Edit share one form with the event-kind switch from the Build agent sheet. On iPad mini and desktop the detail sits beside the list.
