PhoneAndroid · 412×892 — focus card with checklist and routine chat

Final phone design. Checklist pinned at the top of the card, chat with the routine underneath (tap CHECKLIST to collapse it; it also collapses when the composer is focused). Tick the 120px ring → ring and title fly to the header centre; tap the small ring to undo. Avatar opens the drawer with D/K/G and streak. Grab bar under the header reveals the week strip. Today / Week / Month / Year tabs sit at the bottom of the card. Try in chat: "break it down", "add review analytics events", "done with the PR", "how am I doing?". Check circle: an unticked routine always opens the Start sheet — it never ticks through. When the routine already has a day goal item the sheet names it under LOCKED IN (· AGENT TARGET once an agent is bound), because that first item is the one an agent’s {goalId} resolves to. Agent flow: tap the ring on Start Work → Build Agent → Create → Start Agent, then tick both tasks. Every frame on this page shares one live state.
